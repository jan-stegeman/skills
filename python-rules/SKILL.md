# User Rules
- The user has installed `uv` on Windows 11.
- Always use `uv` (`uv tool install`, `uv run`, `uv add`, `uv pip`) instead of standard `pip` or `python -m venv`.
- Format PowerShell commands as concise, runnable single-line expressions.
